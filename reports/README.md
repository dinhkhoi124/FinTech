# Reports

Mentor-facing reporting workspace.

## Structure
Each week contains:
- `daily/` — one note per working day
- `experiments/` — hypothesis/setup/result/decision notes
- `results/` — tables/figures/metric artifacts or links
- `week_XX_summary.md` — progressive weekly summary
- `exports/` — generated PDF/DOCX at review boundaries if created

Use templates from `reports/_templates/`.

## Rule
Reports describe verified work. They must not become a second project plan or fabricate unfinished work.

Canonical source: Markdown.

`week_00/` records repository bootstrap only. `week_01/` through `week_05/` are
the five implementation/evaluation weeks required by the PRD.
