# PayResolve AI

Banking Intent Classification & Grounded RAG for Payment Support.

The project is currently at **Phase 1 — Banking77 benchmark**. W1-001 data locking,
W1-002 lexical validation, and W1-003 semantic validation are complete. The
frozen-test W1-004 comparison has not started.

## Start here

1. Read `AGENTS.md` and the mandatory context it lists.
2. Review current status in `PROJECT_STATE.md` and work items in `TASKS.md`.
3. Use `docs/DEVELOPMENT.md` for stable setup, validation, reporting, and future
   experiment entry-point conventions.

`docs/MASTER_PRD.md` is the authoritative scope. Markdown under `reports/` is the
canonical reporting source; PDF/DOCX files are generated review artifacts only.
